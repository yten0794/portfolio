🛡️ 4대보험·육아휴직 확인서·출산휴가 급여대위 신고 자동화

배경/목적입·퇴사와 휴·복직이 발생할 때 담당자가 여러 인사시스템 메뉴에서 정보를 개별 조회하고, 신고자료를 작성·제출한 뒤 처리 현황을 별도 엑셀로 관리해야 했습니다. 반복적인 조회와 수기 입력으로 신고 누락 및 오입력 위험이 있었고, 신고 대상과 처리 상태를 별도 엑셀 파일로 관리하는 데에도 시간이 필요했습니다.진행내용매일 오전 9시에 Snowflake와 인사시스템에서 발령·신고 대상 데이터를 자동 수집해 4대보험 신고현황 엑셀을 업데이트하도록 구현했습니다. 입사·퇴사·산전후휴가·육아휴직·복직 유형에 따라 신고 대상을 자동 분류하고, 신고일·제출일 입력 여부와 신청일 도래 여부를 기준으로 상태를 신고예정·확인중·확인서 제출필요·완료로 자동 표시했습니다. 국민연금·건강보험·고용·산재 신고 및 출산휴가 확인서·급여대위·육아휴직 확인서 제출에 필요한 데이터를 생성하고, 기관별 신고 페이지 로그인부터 메뉴 접속, 신고자료 작성까지 자동화하였습니다. 또한 n8n 메일 알림과 Notion DB 교차검증을 통해 신고 대상과 처리 상태를 확인할 수 있도록 구성했으며, 실제 신고 전송은 담당자 최종 확인 후 진행되도록 설계했습니다.성과건당 평균 처리시간을 약 10.3분에서 1.2분으로 단축하여 약 88% 절감했습니다. 월 평균 약 1시간 45분의 업무시간이 절감되었으며, 반복 조회·수기 입력을 줄여 신고 누락과 오입력 위험도 낮췄습니다.

🐱 채용 AI Agent 'NAVI' 개발

배경/목적정기공채로 많은 지원자를 짧은 시간 안에 평가해야 하는 환경에서 평가자 간 편차가 발생했습니다. 현업 평가자 1인당 약 400명의 지원서를 3~4일 내 평가해야 했고, 채용담당자가 지원서 데이터를 정리·스크리닝하는 데만 최소 1일 이상 소요되는 문제가 있었습니다. 특히 평가자들이 엑셀 평가표로 지원자를 평가하다 보니, 채용 데이터 분석을 위한 구조화된 데이터 수집도 어려웠습니다. 지원자의 역량을 빠르게 파악하고 평가의 일관성을 높이는 채용 지원 시스템을 만들고자 했습니다.진행내용서류전형에서는 AI가 지원자의 역량을 신호등 형태로 표시하고, 평가 근거를 함께 제시하도록 구현했습니다. 예를 들어 지원서에서 데이터 분석 경험이 확인되면 데이터 분석 역량에 초록불을 표시하고, 해당 경력과 근거를 제시해 평가자가 원문을 빠르게 검토할 수 있도록 했습니다. 면접전형에서는 서류 평가 결과를 기반으로 해당 역량을 다시 검증할 수 있는 맞춤형 심화 질문을 추천하도록 설계했습니다.성과서류 스크리닝 시간을 하루 이상에서 약 30분으로 단축하여 약 94% 절감했습니다. 객관적인 근거를 통해 AI 신호등 기능을 제공하여 평가자 간 편차를 줄이고 채용 평가의 일관성을 높였습니다. 또한 AI 면접 질문 추천을 통해 구조화 면접 설계를 지원했습니다.
